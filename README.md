#### 1. Miller-Rabin Primality Pipeline
For an odd integer $n > 2$, write $n - 1 = 2^s \cdot d$ where $d$ is odd. Select witness $a \in A$:
$$\text{Check: } a^d \equiv 1 \pmod n \quad \text{or} \quad a^{2^r \cdot d} \equiv -1 \pmod n \quad \text{for some } 0 \le r < s$$
If neither condition holds, $n$ is composite.

#### 2. Pollard's Rho Acceleration (Brent's Variation)
Utilizes the pseudo-random sequence $x_{i+1} = (x_i^2 + c) \pmod n$. Brent's cycle-finding replaces the standard Floyd algorithm by stepping in powers of two, reducing the number of costly greatest common divisor ($\gcd$) computations:
$$y = x_i, \quad q = \prod \left| y - x_j \right| \pmod n, \quad g = \gcd(q, n)$$

## 5. Local Development & Deployment

The platform is designed as an ultra-lean, zero-dependency, single-file architecture.

### Quickstart Setup

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/rayaantasnim/Prime-Factorization-Web.git
   cd Prime-Factorization-Web
   ```

2. **Launch Local Environment:**
   No node module installation or build step is required. Serve the root directory using any standard HTTP server:
   ```bash
   # Using Python 3
   python3 -m http.server 8080

   # Using Nodejs npx
   npx serve .
   ```

3. **Access Engine:**
   Open your browser and navigate to `http://localhost:8080`.
